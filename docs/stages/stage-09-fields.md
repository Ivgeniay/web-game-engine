# Этап 9. Поля ввода и стек отмены

Прочитай `CLAUDE.md` и в `docs/ui-catalog.md` раздел «Этап 9», записи TextField, SearchField, NumberField, PropertyRow, VectorField, общие правила полей ввода и общие механизмы «Перетаскивание» и «Отмена и повтор изменений значения». Все правила `CLAUDE.md` действуют на этом этапе. При противоречии главнее `CLAUDE.md`.

Требования к поведению берутся из каталога. Ниже — только решения, которые каталог откладывал до этого этапа, и то, что каталог не покрывает.

## Цель

Поля ввода, из которых строится инспектор: текст, поиск, число с изменением перетаскиванием подписи, вектор, строка «подпись — поле». Протокол изменения значения и стек отмены. В демо-сцене окно Inspector перестаёт быть заглушкой.

## Порядок работы

Пять подшагов по разбивке раздела «Этап 9» каталога, каждый — один логический модуль. Больше подшагов не добавляй. Проектный подшаг 9.1 — короткий: только реальные развилки, которые не решены ниже. После каждого подшага остановись, перечисли созданные и изменённые файлы и жди подтверждения.

Мелкие находки, которые не мешают шагу (особенности браузеров, редкие сочетания, косметика), записывай в `docs/backlog.md` и не останавливайся на них.

## Разрешённые зависимости

Новых пакетов нет.

## Решения, принятые заранее

### Протокол изменения значения

- `preview`, `commit`, `cancel` по каталогу. Поле само отмену не хранит.
- Режим фиксации у TextField и NumberField: при каждом вводе или только по Enter и потере фокуса. По умолчанию — по Enter и потере фокуса.

### Некорректное значение

- Фильтр ввода по каталогу: недопустимый символ не вводится, недопустимая вставка отклоняется целиком.
- При фиксации значение вне диапазона приводится к ближайшей границе.
- Пустое или незаконченное значение (`-`, `.`) при фиксации возвращает последнее корректное.
- Пока значение некорректно, поле показывает состояние ошибки из общих правил каталога.

### NumberField

- Числа отображаются по языку интерфейса, ввод принимает и точку, и запятую как десятичный разделитель.
- Выражения (`2*3`, `+=5`) — не на этом этапе, они в next.
- Большие целые (`long`) — не на этом этапе: поле работает с `number`. Пункт в бэклог.

### Перетаскивание значения

- Модификаторы: с Shift — точнее (шаг ×0.1), с Alt — грубее (шаг ×10).
- Порог начала перетаскивания, чтобы клик по подписи не менял значение.
- Pointer Lock для бесконечного перетаскивания по каталогу, отмена при выходе из захвата.
- Одно перетаскивание — одна запись отмены.

### Стек отмены

- Живёт в `core`, работает с операциями, которые даёт интеграция. Каркас не знает, как движок меняет данные.
- Группировка нескольких изменений в одну запись.
- Команды каркаса «Отменить» и «Повторить» с сочетаниями Mod+Z и Mod+Shift+Z. Интеграция ставит их в своё меню Edit. Пока фокус в текстовом поле с незафиксированным вводом, работает родная отмена браузера — по каталогу.
- Окно истории — не на этом этапе.

### Демо-сцена

- Окно Inspector показывает выбранный объект: имя, Transform (позиция, поворот, масштаб через VectorField) и один-два компонента с числами, флажком и выпадающим списком через PropertyRow.
- Пока деревьев нет, выбор объекта — через Select в верхней части окна Inspector. На этапе 10 его заменит выделение в Hierarchy.
- Изменения идут в стор сцены демо через стек отмены. Пункты «Отменить» и «Повторить» в меню Edit демо работают.
- Заголовков компонентов со сворачиванием пока нет (Foldout и ComponentHeader — этап 10), секции разделяются подписью.

## Критерии приёмки

- Все элементы этапа 9 из каталога есть, у каждого тесты и страница в разделе Components.
- Число меняется перетаскиванием подписи с модификаторами; Esc отменяет перетаскивание; одно перетаскивание — одна запись отмены.
- Целочисленное поле не даёт ввести букву или запятую, значение вне диапазона приводится к границе.
- В демо-сцене можно выбрать объект, поменять его Transform и компоненты, отменить и повторить изменения из меню Edit и сочетаниями.
- `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build` проходят без ошибок и предупреждений, полный прогон после последней правки.

## Что не входит в этап

- Выражения в NumberField, большие целые.
- Окно истории отмены.
- Foldout, ComponentHeader, деревья и списки: этап 10.
- Slider, ColorField и другие расширенные поля: этапы next.

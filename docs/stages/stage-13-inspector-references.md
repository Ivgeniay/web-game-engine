# Этап 13. Инспектор и ссылки

Прочитай `CLAUDE.md` и в `docs/ui-catalog.md` раздел «Этап 13», записи PropertyField, InspectorElement, ObjectField, ObjectPicker (раздел engine-specific), SectionHeader, GridView, Thumbnail, PickerDialog, SearchableMenu, Breadcrumbs, а также запись PropertyRow (слоты отметки и сброса). Все правила `CLAUDE.md` действуют на этом этапе.

Требования к поведению берутся из каталога. Ниже — решения по развилкам.

## Цель

Интеграция описывает свойства своих объектов данными, а инспектор каркаса строит по ним секции сам. Поле ссылки на объект или ассет с окном выбора, сетка значков, иерархическое меню с поиском. В демо-сцене инспектор переходит с ручной вёрстки на этот механизм, появляются ссылки на ассеты и кнопка добавления компонента.

## Порядок работы

Проектный 13.1 — короткий, только по развилкам, которые не решены ниже. Дальше:

- 13.2 — контракт описания свойств, реестр редакторов по типу, встроенные редакторы;
- 13.3 — механизм инспектора, SectionHeader, слоты отметки и сброса в PropertyRow, перевод инспектора демо на механизм;
- 13.4 — GridView и Thumbnail;
- 13.5 — PickerDialog и ReferenceField, ссылки на ассеты в демо;
- 13.6 — SearchableMenu, Breadcrumbs, добавление компонента в демо, документация и итог.

После каждого подшага остановись и жди подтверждения. Отчёт — не длиннее 25–30 строк. Мелкие находки — в бэклог без остановки, явные ошибки в тексте документации исправляй сразу.

## Разрешённые зависимости

Новых пакетов нет.

## Решения, принятые заранее

### Описание свойств

- Контракт описания свойства лежит в `src/contracts`: тип значения, подпись `MessageRef`, ограничения (диапазон, шаг, варианты перечисления, флаги), только чтение, значение по умолчанию, атрибуты отображения (ползунок вместо числа, многострочный текст, скрыть).
- Чтение и запись значений для набора выделенных объектов даёт интеграция. Каркас не знает, как устроены объекты движка.
- Встроенные редакторы каркаса для типов: целое и дробное число, строка, логическое, векторы 2–4, цвет, перечисление, флаги, прямоугольник, объём, список значений любого из этих типов, ссылка. Интеграция регистрирует свои редакторы для своих типов тем же реестром, без правки файлов каркаса.

### Инспектор

- Механизм получает выделение и источник секций от интеграции и строит секции с ComponentHeader и строками свойств.
- Смешанные значения, одна запись отмены на изменение для всех выделенных объектов — через уже существующие механизмы этапов 9–12.
- Интеграция может заменить отрисовку секции своего типа целиком — аналог пользовательского редактора Unity.
- Окно Inspector — по-прежнему окно демо-интеграции, а не каркаса: каркас даёт механизм.
- Слоты PropertyRow: отметка «значение отличается от значения по умолчанию» слева и кнопка «сбросить к значению по умолчанию» справа, по каталогу. Пункт «Сбросить» в меню свойства — тоже.

### Сетка значков и превью

- GridView с виртуализацией по строкам ячеек, масштаб ползунком, при минимальном масштабе переход к виду списка — по каталогу. Выделение и клавиатура как у ListView.
- Thumbnail получает функцию загрузки превью от интеграции, асинхронную, с отменой. Пока превью грузится, показывается иконка-заглушка. Индикатора загрузки нет — он появится на этапе 14.

### Ссылки

- ReferenceField по каталогу: иконка и имя цели, кнопка окна выбора, очистка, приём перетаскивания.
- Поставщик ссылок от интеграции: допустимые типы, имя и иконка по идентификатору, источник элементов для окна выбора, проверка перетаскиваемых данных.
- PickerDialog: поиск, переключение списка и сетки, одиночный клик — предпросмотр в поле, Enter или двойной клик — выбор, Esc — возврат исходного значения. Вкладки «Ассеты» и «Сцена» — через ToggleButtonGroup, отдельного компонента Tabs пока нет.

### Меню с поиском

- SearchableMenu по каталогу: иерархия, поиск, при вводе — плоский список совпадений с путём, «назад» кнопкой и клавиатурой.
- Breadcrumbs по каталогу.

## Демо-сцена

- Секции Transform, Rigidbody, Light, Path, Note описаны данными и строятся механизмом. Ручные секции удаляются.
- Новый компонент со ссылками, например MeshRenderer: ссылка на меш и на материал. Ассеты — из демо-проекта окна Project, с превью в окне выбора.
- Перетаскивание ассета из Project в поле ссылки.
- Кнопка «Add Component» внизу инспектора открывает SearchableMenu со списком компонентов по категориям.
- У свойств с изменённым значением — отметка и сброс.

## Критерии приёмки

- Все элементы этапа 13 из каталога есть, у каждого тесты и страница витрины на двух языках.
- Интеграция описывает свойства данными, регистрирует свой редактор для своего типа и свою отрисовку секции, не правя файлы каркаса — показано примерами на витрине.
- В демо-сцене инспектор построен механизмом, ссылки выбираются в окне выбора и перетаскиванием из Project, компонент добавляется через меню с поиском, всё отменяется.
- `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build` проходят без ошибок и предупреждений, полный прогон после последней правки.

## Что не входит в этап

- Двухпанельный Project, SplitView, Tabs: этап 15.
- Индикатор загрузки превью: этап 14.
- Поиск по свойствам в инспекторе, отметки переопределений префабов: later.
